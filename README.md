# utsabkarki.com.np

Personal site of Utsab Karki. A Halloween-themed real-time 3D wireframe landscape with a moon and bats, built with React 19, Three.js (React Three Fiber), TypeScript, Vite 8 and Tailwind 4.

## Develop

```bash
npm install
npm run dev
```

## Edit the content

All text, links, education, experience and skills live in `src/content.ts`. Photos are in `src/assets`.


## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages (`.github/workflows/deploy.yml`). The custom domain is set by `public/CNAME`.
