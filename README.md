# utsabkarki.com.np

Personal portfolio of Utsab Karki — a real-time 3D landscape built with React 19, Three.js (React Three Fiber), TypeScript, Vite 8 and Tailwind 4.

## Develop

```bash
npm install
npm run dev
```

## Edit the content

All text, links, education, experience and skills live in `src/content.ts`.

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages (`.github/workflows/deploy.yml`). The custom domain is set by `public/CNAME`.
